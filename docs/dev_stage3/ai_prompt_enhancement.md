# AI提示词增强优化

## 优化背景

用户反馈：`buildUnifiedGamePrompt`信息不够完整，AI缺少关键的角色状态信息和历史上下文，无法做出合理的决策。

## 优化前的问题

1. **信息不完整**：只提供基本属性，缺少详细状态信息
2. **缺少历史上下文**：AI不知道角色的历史事件和决策
3. **决策选项不具体**：AI生成的选项过于通用，缺少针对性
4. **缺少强制要求**：AI可能不提供决策选项

## 优化方案

### 1. 完整的角色状态信息

**新增详细状态字段：**
```go
- 教育背景：%s
- 职业情况：%s
- 居住地点：%s
- 婚姻状况：%s
- 家庭情况：%s
- 社会地位：%s
- 健康状况：%s
- 财富水平：%s
- 人际关系：%s
- 个人成长：%s
```

### 2. 历史事件上下文

**buildHistoryInfo()方法：**
- 提供所有历史关键事件
- 包含事件发生年龄、描述和影响
- 让AI了解角色的人生轨迹

**示例输出：**
```
历史关键事件：
1. [18岁] 张三成年了，面临人生的重要选择 - 人生重要节点
2. [22岁] 张三大学毕业，准备踏入职场 - 人生重要节点
```

### 3. 当前决策上下文

**buildCurrentDecisionInfo()方法：**
- 显示当前的决策选项
- 明确角色选择了什么
- 为AI提供决策背景

### 4. 强制决策要求

**明确的任务描述：**
- 决策模式：必须为下一个人生阶段提供新的三个决策选项
- 推进模式：如果生成关键事件，必须同时提供决策选项
- 要求具体、有意义的决策描述

### 5. 增强的规则约束

**新增规则：**
- 必须根据角色当前状态和历史背景生成决策
- 三个决策选项要有明确区别和针对性
- 决策选项必须与当前人生阶段相关

## 优化效果

### AI决策质量提升
- **更准确**：基于完整信息做决策
- **更具体**：针对角色状态的个性化选项
- **更连贯**：考虑历史背景的连续性

### 用户体验改善
- **更真实**：决策选项贴合角色实际情况
- **更有意义**：每个选择都有明确的背景和目的
- **更连贯**：人生故事更加完整和逻辑

### 技术架构
- **向后兼容**：保持原有API接口不变
- **模块化**：新增的辅助方法便于维护
- **可扩展**：便于后续添加更多上下文信息
